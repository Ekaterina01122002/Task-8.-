# Task-8.-Декоратор
----------------

**Описание**:  проект демонстрирует применение паттерна "Декоратор" на примере оформления книги с помощью графического интерфейса JavaFX. Программа позволяет наглядно показывать, как к базовому объекту ("простая книга") можно поэтапно добавлять различные украшения (название, окантовка, закладка и другие), не изменяя исходный класс.  

   **Технологический стек**: 1. Основной язык программирования: Java  
2. Библиотека графического интерфейса: JavaFX  
3. Компоненты визуализации: Pane, Rectangle, Line, Text (классы JavaFX)  
4. Архитектурный паттерн: Декоратор (Decorator Pattern, GoF)
**Скриншот рабочего окна приложения**: Книга с декоративными элементами, реализованными через паттерн Декоратор на JavaFX

## Зависимости

 1.Java Development Kit (JDK) версии 8 или выше  
  Рекомендуется JDK 11 или JDK 17. Некоторые сборки JavaFX могут не поддерживаться в ранних версиях JDK.

2. JavaFX SDK  
  - Начиная с JDK 11 JavaFX не входит в стандартную поставку Java и должен быть установлен отдельно.
  - Загрузить JavaFX можно с официального сайта: https://openjfx.io/.
  - Рекомендуемая версия JavaFX SDK: 11 или выше (версия должна соответствовать вашей версии JDK).
  - Для работы с JavaFX в IntelliJ IDEA или Eclipse потребуется добавить соответствующую библиотеку (SDK) к проекту.

3.  Система сборки  
 - Проект может быть собран с помощью любой стандартной IDE (IntelliJ IDEA, Eclipse, NetBeans), либо с использованием Maven/Gradle (если подготовлен build-скрипт).
- Для компиляции вручную потребуется добавить путь к JavaFX при запуске приложения.


## Установка

1. Установите Java

- Скачайте и установите JDK версии 11 или выше  
- Загрузить JDK (https://adoptopenjdk.net/)  
2. Установите JavaFX
- Скачайте JavaFX SDK версии, соответствующей вашей версии JDK, например:  
  Загрузить JavaFX (https://gluonhq.com/products/javafx/)
- Распакуйте архив в удобную папку, например: C:\javafx-sdk-17.0.8\
3. Скачайте архив с исходным кодом через GitHub


## Конфигурация

1. Откройте проект в вашей IDE

- Создайте новый Java-проект и укажите папку src как исходную.
- Добавьте JavaFX SDK в зависимости проекта (Project Structure → Libraries → Add JavaFX SDK).

## Применение

1. Запустите приложение  
   После установки и запуска программы перед вами откроется основное окно с графическим изображением книги.

2. Добавление украшений (декораторов)  
   В зависимости от реализации, пользователь может выбрать компоненты оформления книги (например: название, золотая окантовка, закладка).

## Проверка ПО

1. Запуск приложения
- Запустите проект в вашей IDE или через командную строку по инструкции из раздела Установка.
- Убедитесь, что окно приложения JavaFX успешно открывается.
2. Отображение книги
- Проверьте, что в окне отображается базовая книга (прямоугольник/объект без декораторов).
3. Проверка декораторов
- Используйте интерфейс, кнопки или настройте начальные значения в коде так, чтобы к книге поочередно добавлялись различные украшения (например: название, золотая окантовка, закладка).
- Каждый новый декоратор должен отражаться визуально на книжной фигуре (например, появление золота по краю, дополнительного текста, значка закладки и т.п.).
4. Проверка описания и стоимости
- Если реализован вывод описания и (или) итоговой стоимости книги, убедитесь, что эти значения корректно меняются при добавлении новых декораторов (например, в текстовом поле или в консоль).
5. Проверка устойчивости
- Попробуйте разные последовательности добавления декораторов, чтобы убедиться в правильности композиции.
- При необходимости проверьте работу с нуля (без декораторов) и с максимальным числом украшений.
6. Отладка
- Если приложение не запускается, проверьте наличие всех зависимостей: корректность путей к JavaFX, версию JDK, корректность всех исходных файлов.
- Ознакомьтесь с выводом в консоль для выявления возможных ошибок.
